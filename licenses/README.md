# License material bundled with releases

This directory is packaged with the application so third-party license information is available alongside the portable runtime.

For Open CASCADE Technology, the Windows build additionally copies the vcpkg package copyright/license material into `bin/licenses` when available.

Official OCCT license sources:

- https://github.com/Open-Cascade-SAS/OCCT/blob/master/LICENSE_LGPL_21.txt
- https://github.com/Open-Cascade-SAS/OCCT/blob/master/OCCT_LGPL_EXCEPTION.txt
- https://dev.opencascade.org/resources/licensing

See the repository-level `THIRD_PARTY_LICENSES.md` for the complete attribution summary.
